# 📄 Weekly Assignment & Deliverables Specification

Assignment Title: Personal Semantic Portfolio Structure

## Scope & Requirements:

1. GitHub Setup: Create a new public repository named scratch2build-personal-portfolio.

2. File Structure: Include `index.html` and a `.gitignore` file.

3. Semantic HTML Requirements:
   - `<header>`: Name, professional title, and nav links.
   - `<section id="about">`: Short bio and goals for Scratch2Build.
   - `<section id="projects">`: An `<article>` list of at least 2 projects with titles,
   descriptions, and placeholder links.
   - `<section id="contact">`: A semantic `<form>` with name, email, subject, and
   message inputs.
   - `<footer>`: Social links and copyright statement.

4. Submission Process: Submit the repository URL and open a Pull Request against your
template branch before the deadline.

**Deadline: Wednesday at 11:59 PM.**

## RAG Status & Follow-Up Criteria

- Green Status: Attended both sessions, completed in-lab HTML portal PR, and submitted portfolio assignments on time.

- Yellow Status: Missed 1 session OR failed to submit the portfolio assignment by Wednesday midnight. Trigger: Pod Lead conducts 15-minute diagnostic check-in on Discord within 24 hours.

- Red Status: Missed both sessions OR submitted no deliverables. Trigger: HR / Technical Lead academic escalation.
